porcupine

Headless product analytics for your agent.

I love PostHog, but I rarely open the dashboard. When I have a question about how people use my product, my agent writes the SQL and draws the graph.

I built Porcupine to self-host that workflow with one Go service and ClickHouse. There’s no admin UI. I can give an agent access to one project or manage the instance from the CLI.

Capture

Send native events or use the supported PostHog and Segment inputs. Browser capture can run without cookies.

Query

Ask your agent which events people triggered this week. It can discover the properties, query the project and plot the results.

Deliver

Forward events to webhooks individually or in batches. Export a query once or send its results to S3 on a schedule.
