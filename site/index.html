Capture, query, deliver

How many conversations did each client start?

$ capture.sh
curl --fail-with-body "$PORCUPINE_URL/capture/" \
  -H "Authorization: Bearer $WRITE_TOKEN" \
  -H 'Content-Type: application/json' \
  --data '{
    "uuid": "0192b530-8600-7000-8000-000000000001",
    "event": "conversation_started",
    "distinct_id": "visitor-17",
    "properties": {
      "client": "acme",
      "conversation_id": "conv-001"
    }
  }'

Use a single-project API token with events:write. Keep the same UUID when retrying.

> analysis.sql
SELECT
  JSONExtractString(properties, 'client') AS client,
  uniqExact(JSONExtractString(
    properties, 'conversation_id'
  )) AS conversations
FROM events
WHERE event = {event:String}
  AND JSONHas(properties, 'conversation_id')
GROUP BY client
ORDER BY conversations DESC
LIMIT 20

Send this SQL to POST /api/v1/projects/{id}/query with parameters: {"event": "conversation_started"} and an events:read API token. Request format ↗

> pipeline.json
{
  "name": "Conversation events",
  "kind": "webhook",
  "webhook": {
    "endpoint": "https://receiver.example.com/events",
    "delivery_mode": "batch",
    "interval_seconds": 300,
    "include_events": ["conversation_started"]
  },
  "credentials": {
    "bearer_token": "DESTINATION_TOKEN"
  }
}

Create with POST /api/v1/projects/{id}/pipelines and pipelines:write plus events:read. This example sends five-minute batches to your HTTPS receiver. Keep the real destination token in a private request file. Scheduled S3 example ↗
