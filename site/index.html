porcupine

Agent-first, self-hosted product analytics.

I love PostHog, but I never open its dashboard. When I have a question about my users, my own agent writes the SQL, analyzes the results, and draws the graphs. I don’t need PostHog’s agents for that.

I built Porcupine to make that workflow easy to self-host. There’s no admin UI. My agent queries the events directly through MCP or HTTP.

Query

Let an agent discover your events and run project-scoped SQL through MCP or HTTP.

Deliver

Forward events to webhooks individually or in batches. Send the results of a scheduled SQL query to S3.
