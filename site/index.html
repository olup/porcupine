porcupine

Self-hosted product analytics for agents.

We built Porcupine because we used PostHog to collect events and never opened its dashboard. Self-hosting the whole stack was more than we wanted to maintain. With Porcupine, our agents query those events directly. We run one Go service, SQLite, and ClickHouse.

Query

Let an agent discover your events and run project-scoped SQL through MCP or HTTP.

Deliver

Forward events to webhooks individually or in batches. Send the results of a scheduled SQL query to S3.
